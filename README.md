# FitOps

Gym management dashboard — members, payments, equipment, inventory, attendance and Muay Thai classes.

```sh
npm install
npm run dev     # http://localhost:8080
npm test        # vitest
```

Sign in with one of the demo accounts listed on the login screen. Credentials are
checked in the browser (see `src/components/auth/AuthProvider.tsx`) — replace that
with a real auth API before using this anywhere real.
